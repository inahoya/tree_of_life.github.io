# v46 復元版

この `index.html` は **v44「終端表示＋省略一括展開」系の公開閲覧アプリ**を復元し、
起動時のデータ経路だけ `all_in_one.json` に一本化した版です。

## GitHub Pages

同じ階層に置きます。

```text
/
├─ index.html
└─ all_in_one.json
```

`all_in_one.json` を更新して GitHub Pages を再読込すれば反映されます。
キャッシュが残る場合は画面上部の「all_in_one再読込」を押してください。

## 維持した閲覧機能

- LIFE / 戻る
- 全省略を展開 / 省略表示に戻す
- 検索（かな正規化）
- 主要グループジャンプ
- 円形 / 横一列
- 日本語 / English / Latin
- 代表種: 重要 / 全部 / OFF
- 比較タブ最大2
- 終端ノードの外側リング
- ノードクリックで系統を移動
- 全経路表示
- 詳細表示
- ホイールズーム
- ドラッグ移動
- 2本指ピンチズーム
- ローカル用単一JSON読込
- フォルダから all_in_one.json 読込

## v45 Editableとの役割分担

- `v45 Editable` = データを編集する
- `v46 index.html` = 公開して閲覧する

v46側には編集フォームを入れません。
