分割ロード

起動時は小さな core だけを保持します。鳥類・哺乳類・両生類・陸上植物・竜弓類は必要時に読み込みます。鳥類は主竜類の中に配置し、検索ではひらがな・カタカナ・半角カナを同一視します。 file:// で開く場合は「データフォルダ選択」で、このパッケージの data フォルダを選んでください。

代表種 v1

代表種は419種。今回+65種は日本国内で自然分布・自然出現するものだけに限定し、菌類・軟体動物・刺胞動物・棘皮動物に加えて、海綿・有櫛・環形・半索・鋏角・多足・甲殻類も補強しました。priority 1 は111種、priority 2 は308種。初期状態は「全部」です。priority 2 はごく薄い灰色で区別できます。またコケ植物（苔類・蘚類・ツノゴケ類）は科を省略し、目から代表種へ直接つなぎます。

コケ植物の表示

勉強用の簡略化として、苔類・蘚類・ツノゴケ類では科を表示しません。 232科を省略し、目までの系統＋代表種で眺められる構成にしています。

菌界＋穴埋め v1

菌界は2024年の19門体系で遅延ロード。さらにCryptista・Haptista・Discoba/Euglenozoa、 灰色植物・紅色植物・緑藻側、Xenacoelomorpha・輪形・紐形・緩歩・有爪動物を追加しました。 深い関係が不安定な場所は多分岐のままです。

LIFE / 真核生物 v1

LIFE直下に真正細菌・古細菌・真核生物を配置し、古細菌内にアスガルド古細菌を追加。 真核側は Metamonada / Amorphea / Diaphoretickes の実用的な部分骨格とし、 Amoebozoa・襟鞭毛虫・SAR（Stramenopiles / Alveolata / Rhizaria）を追加しました。 真核生物の根と古細菌との関係は研究が進行中なので、深部は過度に固定していません。

節足動物 v2

鋏角類・多足類・汎甲殻類を追加。甲殻類は単系統ではないため、 Pancrustacea の中に主要甲殻類系統と Hexapoda → Insecta を配置しています。 階層が深くなったので、ヘッダーの「主要グループへ…」から鳥類などへ直接ジャンプできます。

動物界の骨格 v2

海綿・有櫛・扁形・環形・線形・半索動物を追加。 前口動物は Spiralia / Ecdysozoa、後口動物は Ambulacraria / Chordata に整理しました。 深い系統が議論中の場所や、まだ未実装の小さな門は多分岐・部分系統として残しています。

無脊椎動物 v1

軟体動物は8現生綱まで、棘皮動物は5現生綱＋主要クレード、 刺胞動物は主要亜群・綱まで。まず動物界全体の地図を埋める粒度にしています。 前口動物・後口動物の枝は現時点で実装済みの門だけを表示する部分系統です。

昆虫 v1

昆虫は現生28目まで。シロアリはゴキブリ目、シラミ類はカジリムシ目に含めています。 議論の残る旧翅類・半翅系統の深い分岐は無理に二分しません。

魚類 v1

魚類は今回は目レベルまで。単一の「魚類」ノードは作らず、 脊椎動物→円口類／顎口類→軟骨魚類／硬骨魚類→条鰭類／肉鰭類として表示します。 四肢動物は肉鰭類の中に接続しています。

配置比較

横一列をデフォルトにしました。円形へはいつでも切り替えられます。横一列は深さと親子関係を追いやすい配置です。 横一列ではクリックした円を常に画面中央へ移動します。兄弟が多い場合は左右ドラッグ・ホイールで周囲を確認できます。 省略表示でも選択ノードの直上の親は必ず残し、円形・横一列とも系統は下方向へ伸びます。

表示操作

図の上でマウスホイールを回すと拡大・縮小できます。マウスまたはタッチでドラッグすると表示位置を動かせます。深い系統ではリング間隔を保ったまま全体を少し縮小表示します。

ラベル

長い名前も省略せず、複数行に折り返して全文表示します。

配置ルール

12分岐以下かつ約210°以内に収まる場合は、親ノードの近くへ扇状に配置します。 それを超える大分岐だけ全周配置へ切り替えます。

表示記号

下に表示項目がない分類ノードは、丸の外側に細いリングを付けて終端であることを示します。 lazy-load前の分岐ルートは終端扱いにしません。 「全省略を展開」を押すと、現在の選択経路にある「… N階層」をすべて展開します。 「省略表示に戻す」で通常の圧縮表示へ戻せます。

スマホで使う

初期表示は従来の約2倍に拡大しています。タップ／クリックでノード選択、1本指ドラッグで移動、2本指ピンチで拡大・縮小できます。 GitHub PagesなどHTTPで公開した場合はJSONを自動読込します。 スマホでローカル利用する場合は、ZIPを展開して index.html を開き、 「単一JSON読込（スマホ向け）」から同じフォルダの all_in_one.json を選んでください。 Androidではフォルダ選択の挙動が端末やブラウザで異なるため、all_in_one.json方式を推奨します。

比較タブ

最大2タブ。2つ目は現在の表示を複製して開き、各タブで別の分類群へ移動できます。

省略規則

界・門・綱・目・科・属は必ず表示します。クレードなど、それ以外の階層が連続した部分だけ「…」に圧縮します。「…」をクリックすると、省略された中で最も近い祖先へ戻れます。
