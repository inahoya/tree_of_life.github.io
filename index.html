v46のデータ読込

GitHub Pagesでは起動時に同じ階層の all_in_one.json を自動読込します。 v44の閲覧機能は維持し、分割ロードを公開時の必須経路から外しました。 ローカルの file:// ではブラウザ制限があるため「単一JSON読込」を使えます。

代表種

表示記号

下に表示項目がない分類ノードは、丸の外側に細いリングを付けて終端であることを示します。 「全省略を展開」で現在の経路の省略階層を一括展開し、もう一度押すと省略表示へ戻します。

スマホで使う

タップ／クリックでノード選択、1本指ドラッグで移動、2本指ピンチで拡大・縮小できます。 GitHub Pagesでは all_in_one.json を自動読込します。

比較タブ

最大2タブ。2つ目は現在の表示を複製して開き、各タブで別の分類群へ移動できます。

省略規則
